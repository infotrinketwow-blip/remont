# Квіз «remont.»

- `quiz.html` — сам квіз (один файл, без збірки).
- `admin.html` — адмінка: редагує всі тексти, ціни, варіанти відповідей, логотип, кольори, контакти й куди йдуть заявки. Справа — живий перегляд.

## Як вносити зміни
1. Покладіть `admin.html` і `quiz.html` в одну папку, відкрийте `admin.html`.
2. Змініть що треба (чернетка зберігається в браузері автоматично).
3. Опублікуйте одним із способів:
   - **⬇ quiz.html з змінами** — замініть файл на сайті (працює, коли адмінка відкрита з вашого сайту, а не з диска);
   - **⬇ quiz-config.json** — покладіть поруч із `quiz.html` на сайті, квіз підхопить його сам.

Адмінка не має паролю — не публікуйте її на відкритому сайті або закрийте паролем на рівні хостингу.
